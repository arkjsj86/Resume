# 박종화 이력서 · Resume

9년차 **Unity 클라이언트 프로그래머**의 웹 이력서 프로젝트입니다.
정적 HTML/CSS로 제작하여 **GitHub Pages**에 배포하는 것을 목표로 합니다.

주력 스택은 **C# · Unity**이며, AR · VR · XR · 메타버스 · 시뮬레이션 등 다양한 도메인의
멀티플랫폼(Windows · Android · HoloLens 2) 클라이언트 개발 경험을 담았습니다.

---

## 🎨 선택된 시안

`mockups/` 에 4가지 디자인 톤을 만들어 비교한 뒤, **③ Game Studio (게임 스튜디오)** 를 최종 선택했습니다.

| № | 시안 | 톤 | 파일 |
|---|------|-----|------|
| 1 | Editorial Minimal | 매거진 · 크림색 · 세리프 | `mockups/1-editorial.html` |
| 2 | Dev Terminal | 터미널 · 다크 · 모노스페이스 | `mockups/2-terminal.html` |
| **3** | **Game Studio ★ 선택** | **게임 포트폴리오 · 다크 그라데이션** | **`mockups/3-game-studio.html`** |
| 4 | Modern AI-Era | 모던 · 크림 · 제이드/코퍼 | `mockups/4-modern-ai.html` |

> 시안 비교 페이지: `mockups/index.html`

## 🧩 현재 최종 시안 (Game Studio) 구성

게임 스튜디오 포트폴리오 무드의 다크 테마(마젠타 → 퍼플 → 시안 그라데이션) 단일 페이지 이력서입니다.

**히어로**
- 이름은 작게, **"클라이언트 프로그래머"** 를 메인 헤드라인으로
- 주력 스택 **C# · Unity** 를 골드 그라데이션으로 강조
- 핵심 지표: 경력(9년차) · 메인 스택 · 출시 도메인

**핵심역량 → 프로젝트 앵커 내비게이션**
- 역량 카드를 클릭하면 같은 페이지의 해당 프로젝트로 부드럽게 스크롤
- 도착한 카드는 골드 테두리로 잠깐 하이라이트

**섹션 구성**
1. 핵심 역량 (Capabilities)
2. 기술 스택 — 표 대신 서술형 (주력 / 회사 프로젝트 / AI와 함께 사이드)
3. 경력 타임라인 (7개 회사)
4. 주요 프로젝트 (회사 업무)
5. 출시 작품 · 사이드 프로젝트
6. 학력 · 자격
7. 자기소개 · 연락

**레이아웃**
- 전 섹션 콘텐츠 폭 통일 (좌우 세로선 일치)
- 프로젝트 카드는 풀폭 1열, 색으로 중요도 강조

> 📌 이미지·영상 등 미디어는 **추후 추가 예정** (현재는 텍스트 기준)
